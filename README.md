# YenneY Menu

Single-page interactive menu for YenneY Vietnamese Restaurant (Marina One, East Tower).

## Deploy to Vercel via GitHub
1. Create a new repo on GitHub and push these files (index.html, vercel.json).
2. Go to vercel.com → New Project → Import the GitHub repo.
3. Framework preset: "Other" (it's a static HTML site, no build step needed).
4. Deploy — Vercel will serve index.html at the root URL automatically.
